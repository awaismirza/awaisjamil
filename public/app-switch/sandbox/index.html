App Switch Sandbox

Test an upgrade

Use the separate sandbox app and Stripe’s test checkout to rehearse an Unlimited purchase without a charge.

Install App Switch Sandbox

Download the Apple silicon disk image and drag App Switch Sandbox into Applications. It has its own shortcut library and activation state.

Download sandbox for Mac

Complete a test checkout

Use Stripe’s test card 4242 4242 4242 4242, a future expiry date and any three-digit security code. Keep real card details out of this test. Stripe test card guide

Open Stripe test checkout

Activate on your Mac

On the checkout confirmation page, choose Copy activation code. Open App Switch Sandbox → Enter Code…, paste the code and choose Activate Unlimited. The app displays Unlimited shortcuts after it verifies the test purchase.
