# WordsCut website ownership

WordsCut website source now belongs in the separate public repository
[awaismirza/wordscut-app-web](https://github.com/awaismirza/wordscut-app-web).
The application and its release process remain separate in the private app repository.
The portfolio supplies an external product link to https://wordscut.com.

The paid release remains in preparation. No price, checkout, installer delivery,
new licence terms or payment-account setup is authorized by this website move.
Earlier AGPL licence rights and source offers remain in the product site's terms.
GitHub Pages deployment is informational; enabling commercial checkout requires
separate purchase/delivery and hosting review.

See [migration handoff](qa/handoff-wordscut-external.md) for DNS-deferred status.
